# 舒張壓過低 — 臨床意義

## 定義
舒張壓（DBP）< 60–70 mmHg，或脈壓差（PP = 收縮壓 − 舒張壓）異常增寬。

## 西醫視角

### 生理基礎
舒張壓主要反映兩件事：
1. **周邊血管阻力（SVR）**：阻力越低，舒張壓越低
2. **主動脈彈性**：主動脈硬化會讓收縮壓升、舒張壓反而降

### 常見原因

| 機制 | 具體病因 |
|------|----------|
| 周邊阻力下降 | 敗血症、過敏性休克、自律神經失調 |
| 主動脈瓣閉鎖不全 | 主動脈瓣逆流（脈壓差顯著增寬） |
| 高心輸出量狀態 | 甲亢、嚴重貧血、動靜脈瘻管 |
| 過度用藥 | 血管擴張劑、過多降壓藥 |
| 脫水/低血容積 | 收縮壓與舒張壓均下降 |
| 心臟功能異常 | 心衰竭（某些類型） |

### 臨床評估重點
- **收縮壓是否正常？** → 若收縮壓正常但舒張壓低 = 脈壓差增寬，優先想主動脈瓣問題或高輸出狀態
- **兩者都低？** → 考慮低血容積、休克
- **合併症狀？** → 水腫 + 低舒張壓特別需要排除心臟因素

## 中醫視角

| 可能病機 | 對應症狀 |
|----------|----------|
| 脾腎陽虛 | 水腫、怕冷、舌淡胖 |
| 氣虛下陷 | 疲倦、氣短、脈沉弱 |
| 心陽不振 | 胸悶、心悸、脈遲 |
| 痰濕阻滯 | 體重重、脈濡緩 |
