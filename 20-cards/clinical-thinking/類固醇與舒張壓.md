# 類固醇與舒張壓

## 定義與概念

類固醇（Corticosteroids）分兩大類：
- **糖皮質素**（Glucocorticoids）：prednisolone、dexamethasone、methylprednisolone
- **礦物皮質素**（Mineralocorticoids）：fludrocortisone、aldosterone

對血壓的影響主要取決於**礦物皮質素活性強弱**。

---

## 西醫視角

### 各類固醇的礦物皮質素活性比較

| 藥物 | 糖皮質素效力 | 礦物皮質素效力 | 對 DBP 的影響 |
|------|------------|--------------|--------------|
| Hydrocortisone | 1 | 1 | 中度升高 |
| Prednisolone | 4 | 0.8 | 中度升高 |
| Methylprednisolone | 5 | 0.5 | 輕度升高 |
| **Dexamethasone** | 25–30 | **≈ 0** | **幾乎無影響** |
| Fludrocortisone | 10 | 125 | 顯著升高 |

→ 臨床重點：**同樣叫「類固醇」，對血壓的影響差異極大**

---

### 類固醇升高血壓的機制（通常）

**1. 礦物皮質素效果（最主要）**
```
類固醇 → 結合腎臟 aldosterone 受體
→ ENaC（上皮鈉通道）表現增加
→ Na⁺ 再吸收↑ → 水分滯留 → 血容積↑ → CO↑ → BP↑
```

**2. 強化交感神經反應**
- 上調 α-腎上腺素受體 → 血管對兒茶酚胺的收縮反應↑

**3. 抑制 NO 合成**
- 減少血管舒張 → 周邊阻力↑

**4. 增加 Angiotensinogen 合成**
- 提供更多 RAAS 系統的基質 → 血壓↑

---

### 用了類固醇，舒張壓仍然過低 → 需要排除

| 可能原因 | 說明 |
|----------|------|
| **使用 Dexamethasone** | 幾乎無礦物皮質素效果，對 DBP 影響微乎其微 |
| **主動脈瓣逆流** | 結構性問題，類固醇無法克服 |
| **自律神經失調** | 周邊阻力仍低，常見於糖尿病病人 |
| **同時使用利尿劑** | 類固醇的保水效果被抵消 |
| **同時使用血管擴張劑** | 降壓藥效果大於類固醇升壓效果 |
| **腎上腺功能不足（Addison's）** | 補充類固醇仍不足量 |
| **嚴重貧血或高輸出狀態** | 高 CO 造成 DBP 下降，類固醇無法彌補 |

---

### 類固醇造成「脈壓差增寬」的機制（特殊情況）

大量類固醇 → 血容積大量增加 → **收縮壓升幅 > 舒張壓升幅** → 脈壓差增寬  
→ 表面上看起來「舒張壓沒有跟上」，但實際是收縮壓升太多

---

### 長期類固醇使用的血壓變化時間軸

| 時間 | 變化 |
|------|------|
| 數天內 | 鈉水滯留開始，血壓輕度上升 |
| 數週 | 血壓明顯升高，體重增加 |
| 長期（月–年） | 二次性高血壓，可能需要降壓藥 |
| 停藥後 | 腎上腺抑制，可能出現低血壓（戒斷期） |

---

## 中醫視角

### 類固醇的中醫藥性認識

| 使用狀況 | 中醫理解 |
|----------|----------|
| 短期大量 | 如「壯火之品」，助陽化熱，短暫振奮 |
| 長期使用 | 耗傷腎陰 → 陰虛火旺 |
| 突然停藥 | 腎陽驟虛 → 虛寒諸症 |

### 類固醇引起水腫的中醫病機
- 鈉水滯留 → 中醫角度：脾失健運、水濕內停
- 長期使用後水腫 + 低舒張壓：**脾腎陽虛兼水濕泛濫**的可能性大
- 排濕無效的可能原因：根本是陽虛，非濕邪實證，應以溫陽利水為主（如真武湯方向）
