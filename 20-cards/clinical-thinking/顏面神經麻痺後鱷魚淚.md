# 顏面神經麻痺後鱷魚淚（Crocodile Tears / Bogorad Syndrome）

## 定義
顏面神經麻痺恢復過程中出現「吃東西時流眼淚」的現象。
醫學名稱：Bogorad Syndrome / Crocodile tears syndrome

## 西醫視角

### 機制（神經錯誤再生）
顏面神經（CN VII）受損後，神經纖維開始再生。
再生過程中發生「錯誤導向（aberrant regeneration）」：

原本支配唾液腺的神經纖維 → 長錯路 → 連接到淚腺

結果：
- 進食 → 刺激唾液分泌的神經訊號
- 同時誤觸淚腺 → 流淚

### 時間軸
- 通常在顏面神經麻痺後數週到數月出現
- 代表神經正在恢復中（是恢復的訊號，但路徑錯誤）
- 西醫認為多為永久性，但部分病人會隨時間改善

### 鑑別
| 現象 | 原因 |
|------|------|
| 吃東西流淚 | Bogorad Syndrome（神經錯誤再生）|
| 情緒流淚 | 正常淚腺功能 |
| 角膜乾燥流淚 | 眼輪匝肌無力 → 眨眼不全 → 反射性流淚 |

## 中醫視角
- 淚為肝液，但此處非情志所發
- 屬「液道失調」，與神經傳導的「氣機逆亂」有關
