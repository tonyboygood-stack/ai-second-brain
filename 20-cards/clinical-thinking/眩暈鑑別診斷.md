# 眩暈鑑別診斷

## 定義
眩暈（Vertigo）≠ 頭暈（Dizziness）
- 眩暈：有旋轉感，環境或自身在動
- 首要鑑別：**週邊性** vs **中樞性**（攸關是否緊急）

---

## 鑑別診斷總表

| 疾病 | 眩暈持續時間 | 臨床特色 | 眼震 | 合併神經症狀 | 聽覺症狀 | 輔助診斷 |
|------|------------|----------|------|------------|----------|----------|
| **良性陣發性眩暈（BPPV）** | 數秒鐘，多次復發 | 與姿勢改變有關 | 週邊性 | 無 | 無 | Dix-Hallpike maneuver 陽性 |
| **梅尼爾氏症** | 數小時到數天，多次復發 | Triad：眩暈＋耳鳴＋低頻聽力喪失 | 週邊性 | 無 | 耳脹、耳痛、單側聽力喪失、耳鳴 | 單側低頻聽力喪失 |
| **前庭神經炎** | 數天到數週，單次急性 | 前驅病毒感染（URI） | 週邊性 | 向病側跌倒，無腦幹徵候 | 通常無 | Head thrust test 陽性 |
| **偏頭痛性眩暈** | 數分鐘到數小時，多次復發 | 偏頭痛病史 | 中樞或週邊 | 偏頭痛或視覺前兆 | 通常無 | 所有測試幾乎正常 |
| **椎基底動脈 TIA** | 數分鐘到數小時 | 年長＋心血管危險因子或頸部外傷 | 中樞性 | 常合併腦幹徵候 | 無 | MRI + DWI 顯示血管病灶 |
| **小腦梗塞/出血** | 數天到數週，急性 | 年長＋高血壓 | 中樞性 | 步態不穩、構音障礙、測距不良、吞嚥困難 | 無 | MRI / CT 顯示病灶 |
| **腦幹中風** | 數天到數週，急性 | 年長＋心血管危險因子或頸部外傷 | 中樞性 | 腦幹徵候，尤其 lateral medullary signs | 無 | MRI 顯示病灶 |

## 最重要的臨床分流：週邊 vs 中樞

```
眩暈病人
   │
   ├─ 有神經學症狀？（複視、構音障礙、吞嚥困難、步態不穩、肢體無力）
   │     └─ YES → 中樞性 → 緊急影像學（MRI/CT）
   │
   ├─ Head thrust test 陽性？
   │     └─ YES → 週邊性可能性高（前庭神經炎）
   │
   ├─ 眼震方向隨注視方向改變？
   │     └─ YES → 中樞性
   │
   └─ 與姿勢改變有關？持續數秒？
         └─ YES → BPPV 優先考慮（Dix-Hallpike 確認）
```

## 快速記憶口訣

**週邊性特徵（相對安全）：**
- 眼震固定方向（不隨注視方向改變）
- Head thrust test 陽性
- 無神經學局部症狀
- BPPV / 梅尼爾 / 前庭神經炎

**中樞性警示（需緊急處理）：**
- 眼震方向改變
- 合併神經症狀
- Head thrust test 陰性（中樞眩暈常為陰性）
- 老年＋心血管危險因子
- 急性發作持續不緩解

## 各疾病重點

### BPPV
- 最常見的眩暈原因
- 耳石脫落到半規管
- 治療：Epley maneuver（耳石復位術）

### 梅尼爾氏症
- 內淋巴水腫
- 三聯症：眩暈＋耳鳴＋低頻聽損
- 低鹽飲食、利尿劑

### 前庭神經炎
- 病毒感染後
- Head thrust test 陽性（前庭眼反射受損）
- 類固醇可能有效

### 椎基底動脈 TIA
- **不能錯過的診斷**
- 5D：Diplopia（複視）、Dysarthria（構音）、Dysphagia（吞嚥）、Dizziness（眩暈）、Drop attack
- 立即神經科評估

## 中醫視角

| 中醫病機 | 對應西醫類型 |
|----------|------------|
| 痰濕中阻 | 梅尼爾氏症（濕濁上蒙清竅） |
| 肝陽上亢 | 高血壓相關眩暈（TIA/中風前期） |
| 氣血虧虛 | 貧血、體位性低血壓型 |
| 腎精不足 | 老年退化性前庭功能衰退 |
| 風邪外襲 | 前庭神經炎（病毒感染後） |
