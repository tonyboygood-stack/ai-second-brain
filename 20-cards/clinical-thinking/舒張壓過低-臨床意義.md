# 舒張壓過低 — 臨床意義

## 定義
- 舒張壓（DBP）< 60–70 mmHg
- 或脈壓差（Pulse Pressure = SBP − DBP）> 60 mmHg（異常增寬）

## 西醫視角

### 生理基礎

舒張壓由以下因素決定：

| 因素 | 說明 |
|------|------|
| 周邊血管阻力（SVR） | 阻力↓ → DBP↓ |
| 主動脈彈性/順應性 | 主動脈硬化 → SBP↑、DBP↓（脈壓差增寬） |
| 心輸出量（CO） | CO↑（高輸出狀態）→ DBP↓ |
| 主動脈瓣完整性 | 逆流 → 舒張期血液回流 → DBP急降 |

臨床重要性：
- 冠狀動脈灌注壓（CPP）= DBP − 左心室舒張末壓
- DBP 過低 → 心肌灌流不足 → 對冠心病病人尤其危險
- J-curve 現象：積極降壓治療若 DBP 降得過低，反而增加心肌梗塞風險

---

### 常見原因與鑑別

#### A. 脈壓差增寬型（SBP 正常或偏高，DBP 低）

**1. 主動脈瓣逆流（最重要）**
- 機制：舒張期血液從主動脈回流入左心室，主動脈壓力無法維持
- 典型：脈壓差可達 80–100 mmHg（如 160/60）
- 臨床徵象：
  - Water hammer pulse（洪脈，一起一落感強）
  - Duroziez's sign（股動脈雜音）
  - de Musset's sign（頭部隨心跳點頭）
  - 心尖部聽到舒張期遞減型雜音

**2. 高輸出量狀態**
| 原因 | 機制 |
|------|------|
| 甲狀腺功能亢進 | 心率↑、CO↑、周邊阻力↓ |
| 嚴重貧血 | 代償性血管舒張 |
| 動靜脈廔管 | 血液繞過微血管床 |
| Paget's disease | 骨頭廣泛 AV 連結 |
| 懷孕 | 黃體素造成血管舒張 |

**3. 主動脈硬化（老年人）**
- 主動脈失去彈性 → 收縮壓↑、舒張壓反而下降
- 孤立性舒張壓過低（Isolated diastolic hypotension）常見於 > 70 歲

---

#### B. 收縮壓與舒張壓均低

**4. 自律神經失調**
- 糖尿病自律神經病變（diabetic autonomic neuropathy）
- 帕金森氏症
- 多系統萎縮（MSA）
- 表現：姿勢性低血壓，平躺正常但站立後 DBP 明顯下降

**5. 分佈性休克**
| 類型 | 原因 |
|------|------|
| 敗血性休克 | 細菌毒素 → 血管麻痺性舒張 |
| 過敏性休克 | 組織胺大量釋放 |
| 神經性休克 | 脊髓損傷後交感神經失調 |

**6. 低血容積**
- 脫水、出血
- DBP 與 SBP 均下降，伴隨心跳過速

**7. 藥物過量**
| 藥物 | 機制 |
|------|------|
| Alpha blocker（prazosin、doxazosin） | 周邊血管舒張 |
| 硝酸鹽類 | 靜脈擴張、前負荷↓ |
| 鈣離子拮抗劑（dihydropyridines） | 血管平滑肌舒張 |
| PDE5 抑制劑 | NO 路徑增強 |

---

### 臨床評估流程

```
DBP 過低
   │
   ├─ SBP 正常或偏高？（脈壓差增寬）
   │     ├─ 聽診有無舒張期雜音？→ 主動脈瓣逆流
   │     ├─ 心率快＋代謝亢進？→ 甲亢/貧血
   │     └─ 老年人？→ 主動脈硬化
   │
   └─ SBP 也低？（全面性低血壓）
         ├─ 發燒／感染？→ 敗血症
         ├─ 站立後更明顯？→ 自律神經失調
         ├─ 最近用藥變化？→ 藥物副作用
         └─ 脫水徵象？→ 低血容積
```

## 中醫視角

舒張壓在中醫無直接對應，但可從「脈象」與「病機」理解：

| 可能病機 | 對應症狀 | 對應脈象 |
|----------|----------|----------|
| 脾腎陽虛 | 水腫、怕冷、便溏、疲倦 | 脈沉遲、濡緩 |
| 氣虛下陷 | 氣短、疲倦、內臟下垂感 | 脈虛、細弱 |
| 心陽不振 | 胸悶、心悸、四肢冷 | 脈遲、結代 |
| 陰虛陽亢 | 頭暈、五心煩熱 | 脈細數、弦 |

脈濡緩大合併低舒張壓的臨床思考：
- 濡脈 = 濕盛、脾虛
- 緩脈 = 脾虛、氣機不暢
- 大脈 = 需分辨：有力為邪盛，無力為虛證
- 三者合現 → 脾虛濕盛兼氣機不足的可能性大
