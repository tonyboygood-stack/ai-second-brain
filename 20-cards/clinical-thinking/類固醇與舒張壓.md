# 類固醇與舒張壓

## 定義與概念

類固醇（Corticosteroids）包含糖皮質素（glucocorticoids，如 prednisolone、dexamethasone）與礦物皮質素（mineralocorticoids，如 fludrocortisone）。

## 西醫視角

### 類固醇通常「升高」血壓的機制

| 機制 | 說明 |
|------|------|
| 礦物皮質素效果 | 鈉水滯留 → 血容積增加 → 血壓上升 |
| 強化血管對兒茶酚胺的反應 | 血管收縮力增強 |
| 抑制前列腺素合成 | 減少血管舒張物質 |

→ **長期使用類固醇，通常收縮壓與舒張壓都會上升**，尤其礦物皮質素活性高的藥物（如 hydrocortisone）更明顯。

### 若病人用了類固醇，舒張壓仍然過低 → 可能原因

1. **類固醇劑量低、礦物皮質素活性弱**（如 dexamethasone 幾乎無礦物皮質素效果）
2. **有主動脈瓣逆流或高輸出狀態**，類固醇效果被掩蓋
3. **自律神經失調**，周邊血管阻力仍低
4. **腎上腺功能不足（Addison's disease）**，雖在補充類固醇但仍不足
5. **利尿劑並用**，將類固醇造成的水分滯留抵消

### 特殊情況：類固醇造成脈壓差增寬？
- 高劑量類固醇 → 血容積大量增加 → **收縮壓升更多，而舒張壓相對沒跟上** → 脈壓差可能增寬
- 這不是「舒張壓降低」，而是收縮壓升高為主

## 中醫視角

類固醇在中醫角度屬「陽剛之品」，短期使用如壯火助陽，長期使用耗傷陰液：
- 長期使用 → 陰虛火旺、腎陰虧損
- 停藥後 → 腎陽虛、陰陽兩虛

水腫合併低舒張壓的病人若長期用類固醇：
- 考慮是否為脾腎陽虛兼有類固醇造成的濕熱積聚
